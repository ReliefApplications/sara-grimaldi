# Legal copy: draft text for the legal notice and the privacy policy

Version 1.1, 2026-11-14. Owner: designer. Companion to `design-system.md`
(sections 8.26, 8.27 and 9.8), which defines routes, layout and the content
structure. The developer copies this text into the content files.

**Status: draft, not legal advice.** This text was written by the design
team to describe what the site actually does. It has not been reviewed by a
lawyer. The publisher must check it, complete every placeholder and have it
validated before the site is launched under her name.

Rules used here:

- Every fact that is not known is a placeholder: `[à compléter : …]` in
  French, `[to be completed: …]` in English. They are displayed highlighted
  on the site. No legal fact about the publisher has been assumed.
- Paragraphs are plain strings. Bulleted lines below are `list` items.
  Paragraphs that come after a list are the section's `after` field. Lines
  under "Links" are entries of the section's `links` field.
- No inline code: technical names are set in the quotation marks of the
  language.
- Section `id`s are the same in both languages.
- If the site changes (analytics, a form, embedded video, another host),
  this text must change in the same commit.

What was checked, and when (2026-11-14):

- GitHub's documentation for GitHub Pages states that a visitor's IP address
  is logged and stored for security purposes, whether or not the visitor is
  signed in to GitHub.
- GitHub's General Privacy Statement gives the address "88 Colin P. Kelly Jr.
  St., San Francisco, CA 94107, United States" for GitHub, Inc., and says
  GitHub complies with the EU-U.S. Data Privacy Framework and generally
  relies on the European Commission's standard contractual clauses.
- Not checked: a telephone number for the host (French law asks for the
  host's name, address and telephone number); how long GitHub keeps these
  logs. Both are left as placeholders.
